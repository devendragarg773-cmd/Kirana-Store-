THE FASTEST BRAND — STARTER WEBSITE

Files:
- index.html  = customer home page
- style.css   = premium dark/light responsive design + animations
- script.js   = products, search, cart, wishlist, login/profile and theme
- admin.html  = separate full-page Owner/Admin Panel
- admin.css   = admin dashboard styling
- admin.js    = admin product management demo

Open index.html to run the frontend.

IMPORTANT:
This package is a frontend/demo build using localStorage. For permanent cross-device products, orders, customers, payments and image uploads, connect it to a real backend/database (for example Node/Express + PostgreSQL/Supabase) before production use.
