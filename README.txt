FRESHKART PRO — FRONTEND PACKAGE

This version is a proper polished frontend build:
• Animated grocery homepage
• Premium dark UI
• Responsive mobile layout
• Light/dark-ready settings
• Categories, search, deals, filters
• Product cards, wishlist and cart
• Login/profile form
• Separate full-page Owner/Admin Panel
• Admin dashboard, products, orders, customers, banners, complaints, reviews and settings
• LocalStorage demo persistence

HOW TO RUN:
Open index.html.

IMPORTANT:
This is still a frontend package. LocalStorage is used for the demo, so data is not shared between different phones.
For real cross-device operation, permanent orders/customers/products/images require a backend + database + image storage and authentication.
